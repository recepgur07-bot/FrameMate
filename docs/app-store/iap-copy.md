FrameMate IAP Copy

Access model summary: no account is required to start recording. The first 3 days
are unlimited (local, on-device trial). After that, every user gets a permanent
7-minutes-per-month free recording quota that renews automatically. StoreKit is
only involved when the user chooses to upgrade to Pro — there is no App Store
introductory offer/free trial on the yearly subscription anymore (see manual
App Store Connect step in the access-model implementation plan).

English

- Marketing line
  Start recording instantly, no account needed. Unlimited for the first 3 days,
  then 7 free minutes every month — upgrade to Pro anytime.

- Yearly Pro
  Annual access to FrameMate Pro. Unlimited recording, no monthly quota.

- Lifetime Pro
  One-time purchase for permanent FrameMate Pro access.
